# Consensus Experiment

## Objective

Evaluate consensus strategies among multiple agents.

Agents:

- Planner
- Architect
- Developer
- Reviewer
- Security

---

## Consensus Algorithms

1. Majority Vote
2. Weighted Vote
3. Confidence Aggregation
4. Arbitration Agent

---

## Test Scenarios

### Architecture Dispute

Monolith vs Microservices

### Security Conflict

Performance vs Security

### Cost Conflict

Cloud Native vs Hybrid

---

## Metrics

- Agreement quality
- Time to resolution
- Cost
- Final outcome score

---

## Expected Results

Confidence aggregation expected to outperform majority voting.
