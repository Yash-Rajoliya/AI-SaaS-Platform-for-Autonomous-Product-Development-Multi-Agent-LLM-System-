# Contributing

## Branch Strategy

- main
- develop
- feature/*
- hotfix/*

## Development Flow

1. Fork repository
2. Create branch
3. Write tests
4. Submit PR

## Requirements

- Unit tests required
- Lint must pass
- Security checks must pass
- Documentation updated

## Commit Convention

```text
feat:
fix:
refactor:
docs:
test:
chore:
```
