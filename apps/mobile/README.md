# AI SaaS Mobile App

Mobile companion application for managing autonomous software development agents, deployments, observability, and governance.

## Features

- Authentication
- Agent Management
- Deployment Monitoring
- Observability Dashboard
- Real-Time Updates
- Incident Tracking

## Tech Stack

- Flutter 3.x
- Riverpod
- GoRouter
- Dio
- WebSocket
- Secure Storage

## Development

```bash
flutter pub get
flutter run
```

## Build

```bash
flutter build apk
flutter build ios
```
