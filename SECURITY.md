# Security Policy

## Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x | Yes |

## Reporting Vulnerabilities

Do not create public issues.

Report privately to:

security@company.com

Include:

- Description
- Reproduction
- Impact
- Suggested remediation

## Security Controls

- RBAC
- mTLS
- JWT Authentication
- Audit Logging
- Encryption At Rest
- Encryption In Transit
